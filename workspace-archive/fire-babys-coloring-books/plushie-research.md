# Fire Babys Plushie Research — POD & Small-Batch Options

**Date:** 2026-10-03
**Goal:** Plushie for the $20 bundle (2 coloring books + 1 plushie of RUKO / BOULDER / SIZZLE / CINDER / BLAZE / LORD INFERNO)

---

## TL;DR

- **There is no true print-on-demand plushie service** (nothing like Merch by Amazon for plushies). Every custom-shape plushie requires a manufactured batch.
- **Cheapest viable path:** small-batch custom plush from China — **$2–$5/unit landed** at 100–500 units. This is the ONLY option that fits a $20 bundle.
- **Budsies-style one-offs ($139+) are for prototypes only**, not for sale.
- **⚠️ The $4.00 KDP book price is not feasible.** KDP will reject it (see math below). Books must be priced ≥ ~$5.70 (8.5×11 B&W).
- **$20 bundle is feasible but razor-thin** if Jeff fulfills it himself with author copies + China plushies. **$24.99 is the safer price.**

## The $4.00 KDP problem ⚠️

Jeff's plan prices each coloring book at $4.00 on KDP. **KDP will not allow this price.** The math (from KDP's official printing-cost tables):

- Coloring book = 8.5×11 = **large trim**, black ink.
- 24–110 pages → fixed printing cost **$2.84** (no per-page charge in this bracket).
- $4.00 list price is under $9.99 → **50% royalty rate**.
- Royalty = (0.50 × $4.00) − $2.84 = $2.00 − $2.84 = **−$0.84** → negative, so KDP blocks the listing.
- **Minimum viable list price ≈ $5.70** (just above $2.84 ÷ 0.50).

**Fix options:**
- Price books at **$6.99** → royalty ≈ (0.50 × $6.99) − $2.84 = **$0.66/book**.
- Or use 6×9 trim (regular, $2.30 fixed) at **$5.99** → royalty ≈ **$0.70/book**. (Smaller pages are worse for coloring books, though — 8.5×11 at $6.99 is the better pick.)

## $20 bundle — feasibility math

The bundle can't be sold as a KDP bundle easily, so the realistic path is: **Jeff sells the bundle on firebabys.io and fulfills it himself** using KDP author copies (bought at print cost, no royalty).

| Item | Cost |
|---|---|
| 2 coloring books (author copies @ $2.84 ea) | $5.68 |
| 1 plushie (China batch, landed) | $4.00 |
| Polymailer + packaging + sticker | $1.00 |
| USPS Ground Advantage shipping (CONUS) | ~$6.00 |
| **Total cost** | **~$16.68** |
| **Margin at $20.00** | **$3.32 (16.6%)** |

**Verdict: feasible but thin.** One lost package or return wipes out the margin on several orders.

**Recommended: price the bundle at $24.99** → margin ~$8.31 (33%), which absorbs shipping variance and returns. Keep $20 as a launch-promo price if Jeff wants the psychological price point.

### Scaling note
At 500 plushies, unit cost drops to ~$2.50–$3.00 landed, adding ~$1.50 margin per bundle. At that point the $20 price gets comfortable.

## Legal/safety caveat (do not skip)

Plushies sold as children's toys in the US need **CPSIA compliance** — third-party lab testing for lead/phthalates/flammability, plus tracking labels. Budget **~$200–$500 per design** for initial testing. The China makers above advertise EN71/ASTM/CPSIA, but Jeff should get his own test report for the first production run — especially since this is a children's brand. This is not legal advice; it's the standard requirement for selling kids' toys in the US.

2. **Character ref sheets:** produce clean front/side/back turnaround art for all 6 characters (needed by every plushie maker).
